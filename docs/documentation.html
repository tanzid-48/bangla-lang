ডকুমেন্টেশন

বাংলা-ল্যাং দিয়ে কোড লেখা শুরু করার আগে যা জানা দরকার — ইনস্টলেশন থেকে শুরু করে প্রতিটি কীওয়ার্ড ও উদাহরণ।

ইনস্টলেশন npm

গ্লোবালি ইনস্টল করুন, যেকোনো ফোল্ডার থেকে bangla-lang কমান্ড ব্যবহার করতে পারবেন।

টার্মিনাল
npm i -g bangla-lang-by-tanzid

ইনস্টল হয়ে গেলে যেকোনো .bangla ফাইল চালান:

টার্মিনাল
bangla-lang আপনার-ফাইল.bangla
সরাসরি ব্রাউজারেও চালাতে পারেন — কোনো ইনস্টলেশন ছাড়াই। প্লেগ্রাউন্ড খুলুন →

মৌলিক উদাহরণ

সবচেয়ে সহজ প্রোগ্রাম — একটি বার্তা দেখানো।

hello.bangla
শুরু

দেখাও "হ্যালো বাংলাদেশ!";

শেষ

ভেরিয়েবল ঘোষণা ও গাণিতিক হিসাব।

variable.bangla
শুরু

ধরো ক = 10;
ধরো খ = 5;
ধরো যোগফল = ক + খ;

দেখাও "যোগফল: " + যোগফল;

শেষ

নিয়ন্ত্রণ প্রবাহ

শর্ত যাচাই — গ্রেডিং সিস্টেমের একটি বাস্তব উদাহরণ।

grade.bangla
শুরু

ধরো নম্বর = 75;

যদি (নম্বর >= 80) {
  দেখাও "A+";
} নাহলে যদি (নম্বর >= 70) {
  দেখাও "A";
} নাহলে {
  দেখাও "পরীক্ষায় আরও মনোযোগ দরকার";
}

শেষ

for ও while লুপ — দুই ধরনের পুনরাবৃত্তি।

loops.bangla
শুরু

// গণনা করো লুপ
গণনা করো (ধরো ক = 1; ক <= 5; ক = ক + 1) {
  দেখাও ক;
}

// যতক্ষণ লুপ
ধরো খ = 10;
যতক্ষণ (খ > 0) {
  দেখাও খ;
  ধরো খ = খ - 2;
}

শেষ

ফাংশন ও তালিকা

একটি ফাংশন যা দুইটি সংখ্যার গড় বের করে।

average.bangla
শুরু

কাজ গড়(ক, খ) {
  ফেরত দাও (ক + খ) / 2;
}

ধরো ফলাফল = গড়(20, 30);
দেখাও "গড়: " + ফলাফল;

শেষ

তালিকা (array) নিয়ে কাজ করা, বিল্ট-ইন ফাংশন সহ।

students.bangla
শুরু

ধরো নম্বরসমূহ = [85, 90, 78, 92, 88];

দেখাও "মোট শিক্ষার্থী: " + দৈর্ঘ্য(নম্বরসমূহ);
দেখাও "মোট নম্বর: " + মোট(নম্বরসমূহ);

শেষ
প্রতিটি উদাহরণ সরাসরি প্লেগ্রাউন্ডে কপি-পেস্ট করে চালাতে পারেন — কোনো সেটআপ লাগবে না।
